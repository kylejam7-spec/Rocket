# Icons

`BlackHole.png`: the Next Black Hole product art on its own, transparent, for the Black
Holes Visited leaderboard header. Rendered from `tools/product-images/icons.html#BlackHoleIcon`
(headless Chrome with a transparent background), uploaded to the owner account; its id is
`BlackHole` in `src/ReplicatedStorage/Shared/ProductImages.luau`. The leaderboard tags its
title "InlineIcon" with an Image attribute and `InlineIconController` puts the picture
before the text (`UI/Icon.attach`).

The coin, strength, speed, launch, shop and invite icons stay emoji (user, 2026-10-24). The
drawn versions are in git history (commit ff5b9dd) if they're wanted again.
